# Alex P. Grover Site

This repository now contains a native React single-page site for Alex P. Grover, built with Vite and styled as a mobile-friendly portfolio.

## Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

The build writes static files to the repository root so the site can be served directly from a static host.

## Preview

```bash
pnpm preview
```

## Content

- Homepage content, filters, and project embeds live in `web/src/App.jsx`.
- Layout and theme styles live in `web/src/styles.css`.
- The site includes a local profile portrait in `web/public/images/`.
